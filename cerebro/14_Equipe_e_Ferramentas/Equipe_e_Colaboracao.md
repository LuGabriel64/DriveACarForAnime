# Equipe e colaboração

| Quem | Papel |
|------|-------|

| **Gabxx10** (amigo, co-dev) | desenvolve com o próprio Claude Code |

Especialidades sugeridas (`02_AI_Protocol`): Claude = arquitetura, sistemas, economia, UI, revisão, docs;
Roblox Assistant = propriedades, pequenos scripts, materiais/iluminação.

## Regras de convivência
- O place está em **Team Create**: os dois veem as mudanças um do outro.
- Antes de cada sessão: `git pull` + ler o topo do `01_ChangeLog` no place.
- Não desfazer mudanças recentes do outro sem registrar o motivo.
- `Author` no ChangeLog identifica quem fez ("Claude Code (Lu)", "Claude Code (amigo)"…).
- GitHub sozinho não junta dois places: o jogo é um só (Team Create); o repositório é o elo de documentação.
- As conversas do Claude **não** são compartilhadas entre PCs: tudo o que importa vai para arquivo.
